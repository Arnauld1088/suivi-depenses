CatégorieEnveloppe / moisFixeReste
Nouvelle enveloppe :
Les enveloppes sont à modifier ici uniquement (l'onglet Analyse les affiche en lecture seule). Par défaut elles valent pour tous les mois ; choisis « ce mois seulement » pour une valeur exceptionnelle (badge « ce mois »). Clique sur une catégorie pour voir ses transactions ; la mini-courbe montre les 6 derniers mois, le trait orange est l'enveloppe. « Fixe » = charge incompressible (loyer, factures…) : elle est déduite d'avance du reste à vivre. Les lignes « Correction de solde » sont ignorées. L'épargne prévue (onglet Épargne) est déduite du reste à vivre : elle est « payée en premier ».
Épargne
Nouvel objectif d'épargne
Les versements se saisissent ici, sur chaque objectif. Pour qu'un versement sorte aussi d'un moyen de paiement, saisis-le dans le Journal : Nouvelle transaction → type « Virement » → « Vers un objectif d'épargne ». Il apparaît alors ici, sans être compté comme une dépense. Un versement saisi directement ici ne modifie pas tes soldes. Le versement mensuel prévu est déduit du « reste à vivre » dans l'onglet Budget.

Dettes & créances
Nouvelle dette ou créance
« Enregistrer » crée la transaction dans le Journal (une échéance déjà saisie à la main, même montant et même catégorie dans le mois, est reconnue comme payée). Le remboursement d'une dette est une dépense (catégorie « Dettes ») ; celui d'une créance reçue est un encaissement hors revenus. Les mensualités de dettes apparaissent automatiquement dans « À venir » et dans l'onglet Budget.

Virements dans l'historique
Repère les transferts déjà saisis comme une dépense + un revenu (même date, même montant, deux moyens différents) pour les exclure des statistiques. Rien n'est modifié sans ta validation.
Détail
Nouvelle transaction
Un virement n'est ni une dépense ni un revenu : il déplace de l'argent sans toucher aux budgets, au récap ni au score. Choisis un moyen de destination, un objectif d'épargne, ou les deux.
